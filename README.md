# 密码管理器（Rust）

原 [pswd2.py](pswd2.py) 的 Rust 重写版。单二进制、启动快、数据加密存储。

## 特性

- **安全加密**：主密码 + Argon2id 密钥派生 + AES-256-GCM 认证加密，密码在数据库里是密文而非明文
- **恢复路径**：忘记主密码时，可用「本机机器码」或「密保问卷」（身份证号/手机号码/自定义问题）恢复，恢复后可重设主密码
- **掩码密码输入**：输入密码时每个字符显示黑点「•」（有输入反馈），按 `Tab`（或 `Ctrl+E`）可暂时明文查看，再按一次隐藏；`Esc` 取消。（注：`Ctrl+V` 在 Windows Terminal 被"粘贴"占用，故不用于查看切换）
- **模糊搜索**：直接输入关键词即可跨字段搜索，支持子序列匹配（可跳跃）与中文拼音（整段/首字母），如输入 `wx` 可找到「微信」、`bd` 找到「百度」
- **高亮选择列表**：主界面用 `↑`/`↓`（或 `PgUp`/`PgDn`）在记录间移动高亮，`回车` 打开；高亮跨页连续、自动换页，列表序号从 1 起连续排列
- **回车优先的操作**：新增记录直接保存无需确认；危险操作（删除）默认回车=否
- **查看记录时密码默认掩码**，按 `V` 暂时查看，按 `C` 复制到剪贴板
- **数据栏与原版一致**：应用名称、昵称、用户名、ID、密码、凭证应用、注册凭证、备注、最后修改时间
- **独立迁移工具**：向导式把 pswd2.py 旧数据（dt_data.csv + ps_data.txt）导入新库

## 构建与运行

```bash
# 构建（需要 Rust 工具链：rustup install stable）
cargo build --release

# 运行主程序（首次运行会引导初始化密码库 pswd.db）
target/release/pswd.exe

# 运行旧数据迁移工具
target/release/migrate_legacy.exe
```

```
  [  3] Google
  ...
──────────────────────────────────────────────
❯ ↑↓选择 / [回车]打开 / 输入搜索词 / [A]新增 / [C]修改 / [D]删除 / [S]设置 / [Q]退出
```

- `↑`/`↓`（或 `PgUp`/`PgDn`）在记录间移动高亮（跨页连续、自动换页），高亮行反色显示
- `回车` 打开当前高亮记录（可查看/复制/修改/删除密码）
- `C` 修改 / `D` 删除**直接作用于当前高亮记录**（无需二次选择）
- 直接输入文字回车 → 过滤搜索结果；输入数字 → 直接打开对应编号记录
- `A` 新增、`S` 设置、`Q` 退出
- **设置（`S`）**：切换主页显示方式——「分页显示（每页 15 条）」或「一口气全部输出」，选择持久保存

## 数据文件

- `pswd.db` — SQLite 密码库（`meta` 表存放各封包与盐、显示设置，`records` 表存放记录，密码列为 AES-256-GCM 密文）
- 数据库放在程序运行目录下，与原版行为一致

## 安全说明

- **主密码无法找回**：只保存了派生所需的信息，忘记主密码只能靠恢复路径
- **机器码恢复的代价**：任何能接触本机（拿到机器码）的人可借此解锁，配置时需知晓此权衡
- 恢复路径可在初始化时设置，暂不支持初始化后追加（可删库重建）

## 旧数据迁移

```bash
# 1. 把旧文件 dt_data.csv、ps_data.txt 放在运行目录（或按提示输入路径）
# 2. 运行迁移工具，按向导操作
target/release/migrate_legacy.exe
```

迁移结果会显示成功/失败明细；确认后旧文件会备份为 `.bak`。

代码结构：

| 文件 | 职责 |
|---|---|
| [src/crypto.rs](src/crypto.rs) | Argon2id 派生、AES-256-GCM、KEK 封包、旧 XOR 兼容解码 |
| [src/storage.rs](src/storage.rs) | SQLite 数据层：初始化/解锁/恢复/增删改查/搜索 |
| [src/sort.rs](src/sort.rs) | 排序规则：英文前、中文按拼音、其他最后 |
| [src/ui.rs](src/ui.rs) | 初始化向导与解锁/恢复菜单 |
| [src/migrate.rs](src/migrate.rs) | 旧数据导入核心逻辑 |
| [src/main.rs](src/main.rs) | 主程序交互 UI |
| [src/bin/migrate_legacy.rs](src/bin/migrate_legacy.rs) | 迁移工具向导 |
